# Portafolio John W. Rizzo V.

**Estudiante:** John W. Rizzo V.

## Descripción

Portafolio personal que presenta mi perfil profesional, mis habilidades y certificaciones, mis proyectos y un formulario de contacto. Fue desarrollado como actividad integradora de la asignatura Programación de Sistemas Web.

## Tecnologías utilizadas

- HTML5, con etiquetas semánticas (`header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS3, con variables en `:root`, Flexbox, `:hover` y media queries
- Git y GitHub para el control de versiones
- GitHub Desktop como cliente de Git

## Cómo visualizar el proyecto

1. Clona el repositorio:

```
git clone https://github.com/Jotiux/portafolio-john-rizzo.git
```

2. Abre la carpeta `portafolio-john-rizzo`.
3. Haz doble clic en `index.html` para abrirlo en tu navegador.

No requiere instalación de programas adicionales.
